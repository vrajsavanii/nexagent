## 6. Resource Management & GPU Lifecycle

To ensure zero memory growth, zero context leaks, and maximum battery efficiency:

1. **Deterministic Disposal:**  
   Every scene utilizes [`disposeThreeResources()`](file:///c:/Users/vrajs/Desktop/Personal/Tech/NexAgent/src/lib/3d/materials.ts) on unmount:
   - All `BufferGeometry` instances called with `.dispose()`.
   - All `Material` instances (including multi-material arrays) called with `.dispose()`.
   - All textures released from GPU memory.
   - `WebGLRenderer.dispose()` and `renderer.forceContextLoss()`.
   - Canvas removed from DOM.

2. **Viewport Pausing (`IntersectionObserver`):**  
   Scenes observe their own DOM container. If scrolled out of view, the render loop skips the `renderer.render()` call, dropping GPU consumption to **0%**.

3. **Background Tab Pausing (`document.hidden`):**  
   All scenes listen to `visibilitychange`. When the browser tab is inactive, the render loop halts immediately to preserve laptop battery and mobile resources.

4. **WebGL Context Loss & Restoration:**  
   Canvas handles `webglcontextlost` by triggering the accessible geometric SVG fallback, preventing React application crashes.

## 7. Accessibility & SEO Compliance

1. **HTML First:** 100% of headings, subheadings, metrics, links, and descriptions are rendered as semantic HTML elements outside of the canvas.
2. **Accessible Descriptions:** Every WebGL canvas container has an explicit `role="img"` and descriptive `aria-label` summarizing the spatial visual state.
3. **Screen Reader Hidden Summary:** Dedicated `.sr-only` summary tags describe the system architecture for assistive devices.
4. **Motion Sensitivity:** Respects `(prefers-reduced-motion: reduce)` by disabling continuous ambient rotations, turning off pointer parallax, and disabling packet travel.
5. **No WebGL Hit-Testing Barriers:** All interactive states are accompanied by standard HTML button controls and tab selectors.

## 8. Developer Guide: Adding a New 3D Scene

When creating a new spatial visualizer for the NexAgent ecosystem:

1. **Import from the Spatial System:**
   ```typescript
   import { detectQualityTier, QUALITY_PROFILES, SPATIAL_COLORS } from '@/lib/3d/spatial-language';
   import { disposeThreeResources } from '@/lib/3d/materials';
   ```
2. **Apply the Device Quality Profile:**
   ```typescript
   const qualityTier = detectQualityTier();
   const quality = QUALITY_PROFILES[qualityTier];
   renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, quality.maxDpr));
   ```
3. **Register Observers:**
   - Attach `IntersectionObserver` to the container element.
   - Attach `document.addEventListener('visibilitychange')`.
4. **Dispose Completely:**
   ```typescript
   return () => {
     cancelAnimationFrame(animId);
     observer.disconnect();
     disposeThreeResources({ scene, renderer, geometries, materials, textures });
   };
   ```
